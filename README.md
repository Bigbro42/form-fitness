# FORM. Trainingscoach

Installierbare Web-App für iPhone mit Trainingsplan, Körperkarte und 6-Monats-Tracking.

## Installation

Nach Aktivierung von GitHub Pages unter `Settings → Pages → Deploy from a branch → main / (root)` die URL `https://bigbro42.github.io/form-fitness/` in Safari öffnen und unter **Teilen → Zum Home-Bildschirm** hinzufügen.

## Datenschutz

Trainingsdaten bleiben im Browser auf dem Gerät. Es erfolgt kein automatischer Upload von Trainingseinträgen an GitHub. Regelmäßig unter **Fortschritt** ein JSON-Backup exportieren. Löschst du Browserdaten oder die Web-App, können lokale Einträge verloren gehen.
