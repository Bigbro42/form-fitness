# FORM. HYROX Trainer

Eigenständige, mobil optimierte HYROX-App. GitHub Pages: https://bigbro42.github.io/form-fitness/hyrox/

## Funktionen

- 3 editierbare Pläne: Physio + Kraft/Ausdauer + Mixed Doubles
- Alle 15 vom Athleten genannten Physiotherapie-Übungen, mit konservativer Einstufung
- Satztracking mit Gewicht, Zeit, Wiederholungen, RPE und Kniebeschwerden
- 16-Wochen-Periodisierung, tägliche Knie-Check-ins, Knie-Verlauf
- Gamification nach Yu-kai Chous Octalysis: XP, Level, Erfolge, eigene Trainingswahl ohne Streak-Strafen
- Export/Import als JSON, CSV-Export, lokal gespeicherte Daten
- Installierbare PWA mit Offline-Cache (nach einmaligem Laden)

## Veröffentlichung

GitHub -> Settings -> Pages -> Deploy from a branch -> main / (root). Dann die URL oben aufrufen. GitHub Pages muss aktiv sein, bevor die Adresse erreichbar ist.

Auf iPhone: Safari -> Teilen -> Zum Home-Bildschirm. Android: Chrome -> App installieren bzw. Zum Startbildschirm.

## Wichtig

Die App ist kein medizinisches Rehabilitationsprogramm. Bei 5/10 Knieschmerz bitte sportphysiotherapeutisch untersuchen lassen. Sprung- und tief einbeinige Belastungen nur nach Freigabe. Lokal gespeicherte Daten können bei Browserdaten-Löschung verlorengehen. GitHub Pages synchronisiert keine Trainingsdaten. Regelmäßig JSON-Backup exportieren.

## Technische Einschränkungen

Keine Benutzerverwaltung, kein Cloud-Sync, keine verifizierte automatische Übungserkennung oder individuell medizinische Freigabe. Übungsbibliothek und Workout-Planung sind offline nutzbar, sofern der Browser sie zwischengespeichert hat. Die konkrete Darstellung ist mobil optimiert; vollständige Geräte-Tests stehen noch aus.
